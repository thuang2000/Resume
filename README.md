# Personal Resume Website

This project is a personal resume website created using semantic HTML
and modern CSS.

The website presents my education, professional experience, skills,
activities, volunteer experience, and awards.

## Project Files

- `index.html` contains the structure and resume content.
- `styles.css` contains the page design and responsive layout.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid

## Accessibility and Semantic HTML

The website uses semantic HTML elements, including:

- `header`
- `nav`
- `main`
- `section`
- `article`
- `footer`
- `address`
- `time`
- `dl`
- `ul`

The website also includes:

- Sequential heading levels
- Keyboard focus indicators
- Accessible navigation labels
- Responsive layouts for desktop and mobile screens
- Sufficient text and background contrast
- Semantic dates using the `time` element

## How to Run the Project

1. Download or clone this repository.
2. Make sure `index.html` and `styles.css` are in the same folder.
3. Open `index.html` in a web browser.

No installation or additional software is required.

## Test Cases

### Normal Test Cases

1. Desktop layout test
   - Open the website in a desktop browser.
   - Confirm that all resume sections display correctly.

2. Navigation test
   - Select each navigation link.
   - Confirm that each link moves to the correct resume section.

3. Email link test
   - Select the email address.
   - Confirm that the default email application opens.

### Edge Test Cases

1. Small-screen test
   - Resize the browser to approximately 320 pixels wide.
   - Confirm that content does not overlap or create horizontal scrolling.

2. Keyboard navigation test
   - Navigate using the Tab, Shift+Tab, and Enter keys.
   - Confirm that all links are reachable and have visible focus indicators.

3. Browser zoom test
   - Increase browser zoom to 200%.
   - Confirm that the text remains readable and content is not cut off.
